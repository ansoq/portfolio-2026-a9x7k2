SoundWear-AI

Wearable Directional Sound Awareness Device for the Hearing Impaired
Role · Project Owner, Developer & Researcher
Embedded AIESP32-S3Edge ImpulseTensorFlow LitePCB DesignSOLIDWORKS
Recognition

1st Place among 233 graduation projects across 11 engineering departments at Gaziantep University. Recognized by the university president and the governor. Featured on TRT HABER and GRT TV. Supported for patent application as a novel assistive technology.

SoundWear-AI is a novel AI-powered wearable assistive device that converts environmental sound direction into intuitive haptic feedback for hearing-impaired users. Built around a 4-microphone and 4-vibration-motor architecture, the system identifies the direction of incoming sounds in real time and notifies the user through directional vibration — entirely on-device, with no cloud dependency. It combines embedded AI, custom hardware, mechanical design, and signal processing into a single wearable platform.

Key Contributions

  • AI & Signal Processing. Trained a lightweight sound classification model using Edge Impulse and TensorFlow Lite, achieving 95.9% training accuracy and up to 90% live classification accuracy on the deployed device.
  • Embedded Implementation. Deployed the trained model on an ESP32-S3 microcontroller for real-time on-device inference, integrating sound classification directly with the vibration feedback system.
  • Custom Localization Algorithm. Designed a peak-RMS tracking method using a 250 ms sliding window across the microphone array, improving directional recognition accuracy from 60% to over 90% by capturing the loudest point of each sound event instead of instantaneous readings.
  • Hardware Engineering. Designed and produced a custom PCB integrating the ESP32-S3, two DRV8825 motor drivers, four MEMS microphones, and four vibration motors; performed full hardware integration, assembly, and bring-up.
  • Mechanical Design & Prototyping. Modeled the full wearable assembly in SOLIDWORKS with a multi-mic / multi-motor layout, and produced functional prototypes using TPU filament — chosen for its flexibility and wearability compared to rigid 3D-printing materials.
  • System Performance. Achieved end-to-end latency as low as 300 ms, up to 14 hours of battery life on a single USB-C charge, and 8+ hours of continuous stability testing with zero runtime crashes.

TEKNOFEST 2026 Combat UAV Competition — Ongoing R&D Project

Alpagu

Combat UAV (Fighter UAV) for TEKNOFEST 2026
Role · UAV Simulation & ROS Engineer / Mock Competition Server Developer
PX4 SITLROS 2 HumbleGazebo GardenYOLO + TensorRTREST APIJetson Orin NX

Alpagu is a fixed-wing combat UAV being developed for the TEKNOFEST 2026 Savaşan İHA (Combat UAV) competition. The aircraft features a pusher-motor and V-tail configuration, integrated with the domestically-produced ALACAKART autopilot, an NVIDIA Jetson Orin NX vision computer, and high-gain 5 GHz airMAX antennas for long-range telemetry and FPV. The system is designed for autonomous target lock-on, kamikaze dive missions on QR-coded targets, and real-time avoidance of opponent UAVs and No-Fly (HSS) zones streamed from the competition server. My role on the team focuses on the autonomous software stack: the SITL simulation infrastructure, the mock competition server used for offline algorithm validation, and the GCS ↔ competition-server communication layer.

Key Contributions

  • SITL Simulation Infrastructure. Built a complete Software-in-the-Loop test environment using PX4 SITL autopilot, Gazebo Garden 3D environment, and ROS 2 Humble middleware. Established the autopilot–ROS 2 bridge via MicroXRCE-DDS and the camera-feed bridge via ros_gz_bridge, enabling validation of autonomous flight, target tracking, and avoidance logic before real-flight testing.
  • Mock Competition Server. Developed a REST API–compatible mock competition server (HTTP/JSON over Flask) that replicates the official server's endpoints, data structures, and rules — including telemetry exchange at 1 Hz, multi-UAV opponent scenarios, simulated HSS no-fly zones, and QR-target coordinate streams — allowing the team to run full end-to-end mission tests offline.
  • YOLO Target Detection in Simulation. Integrated a YOLO-based object detection node into the simulation pipeline, processing the nose-mounted camera feed (640×480 @ 30 FPS) and publishing real-time target detections to the autonomous control layer. Verified ~18–19 FPS inference on RTX 3050 with TensorRT FP16, exceeding the 15 FPS minimum requirement.
  • QR Detection & Kamikaze Server Integration. Implemented the QR-target detection pipeline on Jetson Orin NX using NVMM zero-copy buffers and OpenCV QRCodeDetector (Frame → NVMM → map/sync → QR Decode). Built the asynchronous HTTP POST flow that transmits decoded QR content and detection timestamps from the GCS to the competition server within the rule-defined time window — independent of the telemetry stream.
  • GCS ↔ Competition Server Communication. Designed the asynchronous REST API client layer between the C++/Qt-based Ground Control Station and the competition server. Implemented POST flows for telemetry and event data, and GET flows for opponent-UAV positions, HSS coordinates, and QR-target locations — running at 1 Hz over Ethernet HTTP/JSON, decoupled from the RF telemetry path to keep latency low.
  • Mission Test Validation. Successfully executed three mission tests in SITL: (1) Autonomous Flight — takeoff, climb, ~20 m/s cruise at 100 m, target-area transit, and landing; (2) Target Detection & Tracking — reliable YOLO detection of a moving target UAV on TensorRT-accelerated inference; (3) Communication Integration — full REST API round-trip with virtual opponent UAVs and HSS zones, telemetry visualized in real time on the GCS.

PLA Kubbe is an autonomous air defense system designed to detect, track, and engage moving aerial targets up to 10 meters away using computer vision. The system features three critical mission capabilities: engaging moving targets on multiple axes, performing friend-or-enemy identification based on color, and executing specific engagement orders within strict safety and dimensional constraints.

Key Contributions

  • Custom PCB Design. Designed a specialized Power Distribution Board using KiCad with three independent XL4016E1 circuits to provide stable, regulated voltages (19.05 V for Jetson, 12.76 V and 7.31 V for motors) from a single source.
  • Battery Packaging. Engineered a custom 2P6S Li-Ion battery pack using Aspilsan INR18650A28 cells assembled via spot welding, delivering a total capacity of 5.6 Ah with a maximum output of 25.2 V.
  • System Reliability. Implemented high-current copper traces and thermal management on the PCB, while integrating an emergency stop button between the battery and the board to ensure operational safety.
